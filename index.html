Welcome!

We are a team of IT students who love building useful web tools. For this midterm project, we combined HTML, CSS, and JavaScript to create an application that talks to a public API.

Our Project: Language Translator App

Main goal: Help users translate words and short sentences between languages quickly, including Filipino and Cebuano.

  • API used: MyMemory Translation API
  • Technologies: HTML, CSS, JavaScript (fetch + async/await)
  • Extra features: Swap languages, copy result, listen to translation, translation history, dark mode
